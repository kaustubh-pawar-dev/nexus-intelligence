# Data Dictionary

> **All data in this project is SYNTHETIC**, generated by code in this repository.
> It does not describe any real company, customer or supplier.

Observation window: 2023-01-01 to 2025-12-31 (fixed, so results are reproducible).
Default random seed: 42. Each table uses its own random stream derived from `[seed, stream_id]`.

## suppliers (24 rows)

| Column | Type | Description |
|---|---|---|
| supplier_id | string, PK | Format `SUP-0001`. |
| supplier_name | string | Fictional name, unique. |
| country | string | Supplier country, one of 10 configured countries. |
| region | string | Region derived from country. |
| lead_time_mean_days | integer | Average order-to-delivery days. Based on a country baseline plus noise, minimum 3. |
| on_time_delivery_rate | decimal | Underlying probability a delivery arrives on time, between 0.70 and 0.995. Drives simulated delays in later steps. |
| defect_rate | decimal | Underlying share of defective units, between 0 and 0.08. |
| payment_terms_days | integer | One of 15, 30, 45, 60, 90. |
| onboarded_date | date | When the supplier was onboarded. Always before 2023-01-01. |

## products (120 rows)

| Column | Type | Description |
|---|---|---|
| product_id | string, PK | Format `PRD-0001`. |
| sku | string, unique | Format `SKU-<CATEGORY CODE>-0001`. |
| product_name | string | Fictional product name. |
| category | string | One of 6 categories, 20 products each. |
| supplier_id | string, FK | References `suppliers.supplier_id`. |
| unit_cost | decimal | Cost per unit, at least 2.00. Sampled log-uniformly within a category range. |
| list_price | decimal | `unit_cost * (1 + markup)`, with a category-specific markup. Always greater than `unit_cost`. |
| launch_date | date | Between 2020-01 and mid-2024. |
| is_active | boolean | Status flag as of 2025-12-31. About 8% of products are inactive. |

## Known simplifications

- These two tables are clean. Deliberate data-quality defects are injected in a later step.
- Categories are evenly balanced (20 each) for simplicity, which real catalogs rarely are.
